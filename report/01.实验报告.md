# 基于 CADT 模型的 EEG 情绪回归实验报告

## 1 实验概述

本实验基于 **CADT (Conditional Adversarial Domain Adaptation for Time Series)** 框架，针对 DailyEEG 数据集进行跨域情绪回归任务。实验通过域对抗学习技术，实现 EEG 情绪特征在不同被试和不同天之间的迁移学习。

### 2.3 数据标准化处理

#### 2.3.1 原始数据预处理流程

1. **EEG 信号采集**：使用 64 通道 EEG 系统采集（实际使用 59 个通道）
2. **带通滤波**：0.5–40 Hz
3. **伪迹去除**：基于 ICA 自动去除眼电/肌电伪迹
4. **重采样**：降采样至 200 Hz
5. **片段提取**：以 10 秒 (2000 点) 为窗口进行无重叠切分

#### 2.3.2 特征标准化方法

采用 **Z-Score 标准化** 对 EEG 信号进行归一化。根据实验目的不同，支持以下三种标准化粒度：

**(1) Sample 标准化**

$$x_{norm} = \frac{x - \mu_{sample}}{\sigma_{sample} + \epsilon}$$

- $\mu_{sample}$：单样本所有时间点的均值
- $\sigma_{sample}$：单样本所有时间点的标准差
- $\epsilon = 10^{-6}$：防止除零的平滑项
- **粒度**：逐样本、逐通道（每个 (seq_len, x_dim) 样本独立归一化）
- **应用场景**：所有 split_mode（cross_subject、cross_day、within_subject_day）

**(2) Day 标准化**

$$x_{norm} = \frac{x - \mu_{day}}{\sigma_{day} + \epsilon}$$

- $\mu_{day}$：同一天所有被试、所有样本的均值
- $\sigma_{day}$：同一天所有被试、所有样本的标准差
- **粒度**：按天分组（跨被试归一化）
- **应用场景**：cross_subject 模式（按天标准化）

**(3) Subject 标准化**

$$x_{norm} = \frac{x - \mu_{subject}}{\sigma_{subject} + \epsilon}$$

- $\mu_{subject}$：同一被试所有天、所有样本的均值
- $\sigma_{subject}$：同一被试所有天、所有样本的标准差
- **粒度**：按被试分组（跨天归一化）
- **应用场景**：cross_day 模式（按被试标准化）

**标签范围**：情绪标签为 5 点 Likert 自评分表，范围 [1, 5]，**未做归一化**，直接使用原始分值

## 3 模型结构
![CADT模型完整训练流程图](./deepseek_mermaid_20260803_0fc248.svg)
### 3.1 整体架构

CADT 模型采用 **双分支架构**，通过域对抗学习实现域不变特征提取和域特定特征分离。

```
输入 EEG (B, 2000, 59)
        │
        ▼
  ┌─────────────────────────────┐
  │     CNNEncoder (双分支)      │
  │  ┌───────────┐    ┌─────────┐ │
  │  │  分支1     │ ->│  分支2  │ │
  │  │ feature_10 │<- │feature_20│ │
  │  │ feature_11 │   │feature_21│ │
  │  └───────────┘    └─────────┘ │
  │   交叉连接 (linear1/linear2)│
  └─────────────────────────────┘
        │              │
        ▼              ▼
    zsc (B, 8)      zs (B, 8)
   域不变特征       域特定特征
        │              │
        ▼              ▼
  ┌──────────┐  ┌───────────────┐
  │Regression│  │MultiDomain    │
  │  Head    │  │ Classifier    │
  │(Linear)  │  │(非对抗分类)    │
  └──────────┘  └───────────────┘
  (11维情绪)         (源域分类)
  
        │
        ▼
  ┌───────────────┐
  │MultiDomain    │
  │Discriminator  │
  │(对抗训练)      │
  └───────────────┘
```

### 3.2 CNNEncoder 详解

双分支特征提取器，包含跨分支连接和旁路残差连接。输入形状 `(B, 59, 2000)`，输出两个 8 维嵌入。

#### 整体数据流

```
输入 (B, 59, 2000)
    │
    ├──→ feature_10 (分支1浅层) ──→ c (B, 128, 2000)
    │                                    │
    │                               ┌────┴────┐
    │                               │ linear2 │ 交叉连接
    │                               └────┬────┘
    │                                    │
    ├──→ feature_20 (分支2浅层) ──→ d (B, 128, 2000)
    │                                    │
    │                               ┌────┴────┐
    │                               │ linear1 │ 交叉连接
    │                               └────┬────┘
    │                                    │
    │                            c2 = c + linear2(d)
    │                            d2 = d + linear1(c)
    │                                    │
    ├──→ feature_22 (旁路池化) ──→ e (B, 128, 1)
    │
    │   ┌────────────────────────────────┤
    │   ▼                                ▼
    │  feature_11(c2)               feature_21(d2) + e
    │   │                                │
    │  AvgPool(2000)                 AvgPool(1998)
    │   │                                │
    │  Flatten(128)                 Flatten(128)
    │   │                                │
    │  fc11: Linear(128→8)          fc21: Linear(128→8)
    │   │                                │
    ▼                                    ▼
  zsc (B, 8)                        zs (B, 8)
  域不变特征                        域特定特征
```

#### 分支 1 详细结构

**feature_10（浅层特征提取）**

| 层 | 类型 | in_ch | out_ch | kernel | stride | padding | bias | 输出形状 |
|----|------|-------|--------|--------|--------|---------|------|----------|
| 1 | Conv1d | 59 | 128 | 7 | 1 | 3 | ❌ | (B, 128, 2000) |
| 2 | BatchNorm1d | 128 | - | - | - | - | - | (B, 128, 2000) |
| 3 | ReLU | - | - | - | - | - | - | (B, 128, 2000) |
| 4 | Conv1d | 128 | 128 | 5 | 1 | 2 | ❌ | (B, 128, 2000) |
| 5 | BatchNorm1d | 128 | - | - | - | - | - | (B, 128, 2000) |
| 6 | ReLU | - | - | - | - | - | - | (B, 128, 2000) |

→ 输出 `c`: `(B, 128, 2000)`

**feature_11（深层特征提取）**

| 层 | 类型 | in_ch | out_ch | kernel | stride | padding | bias | 输出形状 |
|----|------|-------|--------|--------|--------|---------|------|----------|
| 1 | Conv1d | 128 | 256 | 5 | 1 | 2 | ❌ | (B, 256, 2000) |
| 2 | BatchNorm1d | 256 | - | - | - | - | - | (B, 256, 2000) |
| 3 | ReLU | - | - | - | - | - | - | (B, 256, 2000) |
| 4 | Conv1d | 256 | 128 | 3 | 1 | 1 | ❌ | (B, 128, 2000) |
| 5 | BatchNorm1d | 128 | - | - | - | - | - | (B, 128, 2000) |
| 6 | ReLU | - | - | - | - | - | - | (B, 128, 2000) |
| 7 | AvgPool1d | 128 | - | 2000 | - | - | - | (B, 128, 1) |

→ 全局池化 → Flatten(128) → Linear(128→8) → **f1: (B, 8)**

#### 分支 2 详细结构

**feature_20（浅层特征提取）**

| 层 | 类型 | in_ch | out_ch | kernel | stride | padding | bias | 输出形状 |
|----|------|-------|--------|--------|--------|---------|------|----------|
| 1 | Conv1d | 59 | 128 | 7 | 1 | 3 | ❌ | (B, 128, 2000) |
| 2 | BatchNorm1d | 128 | - | - | - | - | - | (B, 128, 2000) |
| 3 | ReLU | - | - | - | - | - | - | (B, 128, 2000) |
| 4 | AvgPool1d | 128 | - | 21 | 1 | 10 | - | (B, 128, 2000) |

→ 输出 `d`: `(B, 128, 2000)`

**feature_22（旁路全局池化）**

| 层 | 类型 | kernel | stride | 输出形状 |
|----|------|--------|--------|----------|
| 1 | AvgPool1d | 2000 | - | (B, 128, 1) |

→ 输出 `e`: `(B, 128, 1)` — 直接对浅层特征做全局平均池化

**feature_21（深层特征提取）**

| 层 | 类型 | in_ch | out_ch | kernel | stride | padding | bias | 输出形状 |
|----|------|-------|--------|--------|--------|---------|------|----------|
| 1 | Conv1d | 128 | 128 | 5 | 1 | 1 | ❌ | (B, 128, 1998) |
| 2 | BatchNorm1d | 128 | - | - | - | - | - | (B, 128, 1998) |
| 3 | ReLU | - | - | - | - | - | - | (B, 128, 1998) |
| 4 | AvgPool1d | 128 | - | 1998 | - | - | - | (B, 128, 1) |

→ 输出 + `e`（残差连接）→ Flatten(128) → Linear(128→8) → **f2: (B, 8)**

#### 跨分支连接

| 组件 | 结构 | 作用 |
|------|------|------|
| linear1 | Linear(128→128) | 分支1 → 分支2：`d2 = d + linear1(c)` |
| linear2 | Linear(128→128) | 分支2 → 分支1：`c2 = c + linear2(d)` |

#### 输出层

| 组件 | 结构 | 输入 | 输出 | 含义 |
|------|------|------|------|------|
| fc11 | Linear(128→8) | feature_11 输出 | (B, 8) | zsc：域不变特征 |
| fc21 | Linear(128→8) | feature_21 输出 + e | (B, 8) | zs：域特定特征 |

#### 设计特点

1. **无 bias 卷积层**：所有 Conv1d 设 `bias=False`，因为后接 BatchNorm1d（BN 自身有偏移参数）
2. **长度自适应**：AvgPool1d 的 kernel_size 使用 `seq_len`（参数化），适配任意序列长度
3. **交叉注意力**：两个分支互相通过线性层交换信息，实现跨分支特征融合
4. **旁路残差**：feature_22 提供浅层全局信息给深层输出，避免梯度消失
5. **感受野差异**：分支1使用更大感受野（k=7,5,5,3）捕获多尺度时间特征；分支2使用 k=7,5 + 局部池化（k=21）捕获局部时间模式

## 4 损失函数

### 4.1 回归损失 (Regression Loss)


$$L_{reg} = SmoothL1Loss(ŷ, y)$$

$SmoothL1(\hat y_i, y_i)=\frac{1}{N}\sum_{i=1}^{N}\left\{\begin{matrix}
0.5*(\hat y_i -y_i)^2, if \left | y_i -y_i \right | <1\\
\left | y_i -y_i \right |-0.5,   otherwise
\end{matrix}\right.  $

- 类型：Huber 损失（对异常值更鲁棒）
- 作用：最小化情绪预测误差

### 4.2 回归感知球形对比损失 (Regression-Aware Contrast Loss)


$L_{sphere} =\frac{1}{N} Σᵢ Σⱼ w(yᵢ, yⱼ) × ||zscᵢ - zscⱼ||²$


其中权重：

$w(yᵢ, yⱼ) = exp(-||yᵢ - yⱼ||² / (2τ²))$

**符号说明**：

- $N$：batch size，即批内样本数
- $i, j$：**均指 batch 内样本的索引**（$\sum_i \sum_j$ 是对批内所有样本两两配对求和），与情绪维度无关
- $zsc_i$：第 $i$ 个样本经 L2 归一化后的球形对比特征（向量）
- $y_i$：第 $i$ 个样本的回归标签（11 维情绪向量，取值 [1,5] 的 Likert 分）
- $\|y_i - y_j\|^2$：两样本标签向量的欧氏距离平方，一次性把 11 个情绪维度都算进去（不对每个情绪维度单独求和）
- 自配对项 $i=j$ 通过掩码 $mask = 1 - I_N$ 置零

**参数与机制**：

- **机制**：标签相似的样本在特征空间中被拉近（权重越接近 1）；标签差异大的样本对贡献接近 0（无显式排斥项）
- **温度参数 τ**：控制标签相似性的软分配强度（τ=1.0），τ 越大权重分布越平滑，τ 越小越倾向于只拉近标签几乎相同的样本

### 4.3 域混淆损失 (Domain Confusion Loss)


$L_{confusion }= KL_{Div}(softmax(disc_{logits}), uniform(1/M))$


- **机制**：使判别器无法区分不同源域
- **实现**：将判别器输出推向均匀分布，实现域不变性

### 4.4 域分类损失 (Domain Classification Loss)


$L_{domain} = CrossEntropyLoss(classifier(zs), domain_{label})$


- **机制**：保证域特定特征 zs 保留域判别信息
- **数据增强**：配合 segment_exchange/segment_remove/segment_shuffle 生成增强样本

### 4.5 总损失


$L_{total} = L_{reg} + λ₁·L_{sphere} + λ₂·L_{confusion} + λ₃·L_{domain}$

| 增强方法 | 描述 |
|----------|------|
| segment_noise | 添加高斯噪声 (σ=0.1) |
| segment_shuffle | 随机反转一段片段 |
| segment_exchange | 随机交换两段片段位置 |
| segment_remove | 随机移除一段片段并用零填充 |

### 5.5 Batch 采样策略

采用 **MultiSourceBatchSampler**：
- 每个 batch 从每个源域取相同数量的样本
- batch_size = 256，按源域数量均分
- 样本数少的域自动循环采样

- **Overall R²**（简称 R²）：把所有样本 × 11 个情绪维度拼成一个大向量后计算的 R²，反映模型整体方差解释能力

## 8 显著性检验

### 8.1 Cross-Day 跨被试 ANOVA 检验

检验不同被试的跨天性能是否存在显著差异（单因素 ANOVA，以被试为分组变量）：

|------|----------|------|--------|
| Test R² | 85.84 | < 0.001 | ** |
| Test MSE | 169.48 | < 0.001 | ** |
| Test MAE | 350.18 | < 0.001 | ** |

> **说明**：所有指标均显示被试间存在极显著差异 (p < 0.001)，表明不同被试的跨天迁移难度差异巨大。

### 8.2 三种设置的整体 ANOVA 检验

检验三种跨域设置（Cross-Subject / Cross-Day / Within-Subject-Day）之间的整体性能差异：

| 指标 | F 统计量 | p 值 | 显著性 |
|------|----------|------|--------|
| MSE | 1.03 | 0.373 | ns |
| MAE | 1.66 | 0.213 | ns |
| R² | 0.29 | 0.754 | ns |
| **Pearson** | **8.02** | **0.002** | ** |
| **Spearman** | **11.05** | **< 0.001** | ** |

> **说明**：在 Pearson 和 Spearman 相关系数上，三种设置存在显著差异。在 MSE/MAE/R² 上差异不显著，可能是由于 Cross-Day 结果方差较大所致。

### 8.3 两两比较（Bonferroni 校正）

对三种设置进行两两 t 检验（α = 0.05/3 = 0.0167）：

#### R² 对比

| 对比 | t 统计量 | 原始 p 值 | 校正后 p 值 | 显著性 |
|------|----------|-----------|-------------|--------|
| Cross-Subject vs Cross-Day | -1.07 | 0.300 | 0.899 | ns |
| **Cross-Subject vs Within-Subject-Day** | **-5.79** | **0.001** | **0.004** | ** |

## 9 结果分析

### 9.1 三种设置的性能对比

1. **Within-Subject-Day（最稳定）**
   - Test R² = 0.180 ± 0.013（最高且最稳定）
   - Test Pearson = 0.167 ± 0.047（显著高于其他设置）
   - 跨 5 个 seed 表现出良好的可复现性

2. **Cross-Day（被试间差异最大）**
   - 平均 Test R² = 0.168 ± 0.212
   - 被试间性能差异极大（R² 从 -0.205 到 0.542）
   - 部分被试（6, 14）跨天迁移效果好，部分被试（8, 15）效果差

3. **Cross-Subject（中等稳定）**
   - Test R² = 0.108 ± 0.025
   - MSE 最低 (0.700 ± 0.020)
   - 在相关指标（Pearson/Spearman）上表现较弱

### 9.2 指标间差异分析

- **MSE vs R² 的矛盾**：Cross-Subject 的 MSE 最低但 R² 也最低，说明其预测偏差较小但模型无法捕捉标签的方差结构
- **Within-Subject-Day 优势**：在 Pearson/Spearman 相关系数上显著优于其他设置，说明其预测值与真实值的线性相关性最好
- **Cross-Day 高方差**：大的标准差 (R² std=0.212) 说明被试个体差异是影响跨天迁移的主要因素

### 9.3 各情绪维度分析

- **表现最好的情绪**：`hostile` 和 `ashamed` 在 Within-Subject-Day 下取得了正 R²（分别为 +0.002 和 +0.000）
- **表现最差的情绪**：`inspired` 和 `determined` 在 Cross-Subject 下 R² 最低（-0.408 和 -0.570）
- **总体趋势**：Within-Subject-Day 在所有情绪维度上均优于 Cross-Subject

## 10 结论

### 10.1 主要发现

1. ✅ **成功将 CADT 框架应用于 EEG 情绪回归任务**
2. ✅ **跨域情绪识别**：在三种域适应设置下均取得合理的预测性能
3. ✅ **多 seed 可复现性**：Cross-Subject 和 Within-Subject-Day 的标准差较小（R² std < 0.025），结果稳定
4. ✅ **统计显著性验证**：Within-Subject-Day 与 Cross-Subject 在 R² 和 MSE 上存在显著差异
5. ✅ **被试个体差异**：Cross-Day 实验显示被试间存在极显著差异 (p < 0.001)

### 10.2 局限性

1. 情绪标签为自报数据，存在主观偏差
2. 部分情绪维度的预测性能仍较差（多数 R² < 0）
3. Cross-Day 实验中方差较大，受被试个体差异影响明显
4. 模型在小样本域的泛化能力有限

### 10.3 标准化策略对比结论

1. **Cross-Subject + Day 标准化**：整体指标略降，但逐情绪 R² 大幅改善（`inspired` +0.405, `determined` +0.460, `afraid` +0.146），说明按天归一化有助于消除跨天方差，提升情绪维度预测
2. **Cross-Day + Subject 标准化**：所有 11 个情绪维度 R² 均改善，`test_avg_r2` 从 -0.321 提升到 -0.015，且方差大幅减小，说明按被试归一化能稳定跨天迁移性能
3. **整体趋势**：按域分组标准化（Day/Subject）比逐样本标准化在逐情绪任务上更有效，尤其在高方差情绪维度上改善显著

### 10.4 未来改进方向

1. 引入注意力机制增强时序特征提取
2. 使用更精细的域对齐方法（如 CORAL、MMD）
3. 探索被试个性化的迁移策略
4. 结合频域特征（DE 特征）与时域特征
5. 增加更多被试和更多 seed 以提升统计功效
